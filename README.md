# 보험 AI 규제 보드

보험사가 AI를 **인수심사 · 보험료 산정 · 보험금 지급 · 보험사기 탐지 · 상담·판매 · 전사 거버넌스**에 쓸 때
챙겨야 할 국내외 규제를 한곳에 모아 매주 갱신하는 보드입니다.

공개 주소: https://shkim820-commits.github.io/insurance-ai-reg-board/

## 구성

| 영역 | 내용 |
|---|---|
| 다가오는 일정 | 보험사 대응이 필요한 날짜. 60일 안에 다가온 일정은 빨간색 |
| 업무별로 보기 | 업무 × 관할 매트릭스. 칸을 누르면 상세 카드로 이동 |
| 전체 항목 | 관할·업무·상태 필터와 검색 |

각 카드에는 구속력(법적 의무 / 감독 기대 / 자율 규범), 보험에서 요구하는 내용,
최근 변동과 다음 일정, 출처 등급과 원문 링크가 들어 있습니다.

## 출처 등급

- **T1** 법령 원문·감독기관 공식 발표
- **T2** 공신력 있는 2차 자료(로펌 해설·업계지)
- **T3** 재확인이 필요한 항목

## 갱신 방법

보드는 `index.html` 한 파일로 되어 있고, 데이터는 파일 안 `<script>`의 세 상수에 들어 있습니다.

- `ASOF` — 기준일. 갱신할 때마다 바꿉니다.
- `ITEMS` — 규제 항목 배열
- `EVENTS` — 다가오는 일정 배열

항목을 고친 뒤 `git add -A && git commit -m "..." && git push` 하면 GitHub Pages에 반영됩니다.

### 항목을 고칠 때 지키는 것

- 다른 규제 보드의 내용을 옮겨 오지 않고, 법령정보센터·금융위·금감원·EIOPA·IAIS·NYDFS 같은 원문으로 채웁니다.
- 원문을 확인하지 못한 항목은 `tier:'T3'`로 두고, `change`에 무엇을 확인하지 못했는지 적습니다.
- `status`는 `new`(최근 60일 안에 공표·개정·시행), `draft`(확정·시행 전), `keep`(확인된 변동 없음) 중 하나입니다.
